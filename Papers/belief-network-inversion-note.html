Belief Network Inversion: Algorithm II, Notes & References

Algorithm II (improved) — with alternative formulations, methodological notes, and bibliography

Setup

Let there be $I$ images and $J$ labels. Each image $i$ is linked to each label $j$ by a certitude $f_{ij} \in [0,1]$, modelled as a clipped Gaussian: \[ f_{ij} \sim \mathcal{N}(\mu_{ij},\, \sigma_{ij}^2) \;\text{ clipped to } [0,1]. \] Collect the means into the matrix $\bar{F} = [\mu_{ij}]_{I \times J}$. The forward map predicts label certitudes from image weights: \[ L = \bar{F}^{\!\top} \Phi, \qquad L \in [0,1]^J, \quad \Phi \in [0,1]^I, \quad \Phi \geq 0,\quad \textstyle\sum_i \phi_i \leq 1. \]

The inverse problem is: given an observed label vector $\ell \in [0,1]^J$, find the image-weight distribution $\Phi$ that best explains it. We measure fit by the sup-norm misfit \[ M(\Phi) = \bigl\|\ell - \bar{F}^{\!\top}\Phi\bigr\|_\infty = \max_{j=1}^{J}\;\bigl(\ell_j - (\bar{F}^{\!\top}\Phi)_j\bigr), \] and define the minimum misfit $M^* = \min_{\Phi \in P}\, M(\Phi)$, where the feasible polytope is $P = \{\Phi : \phi_i \geq 0,\; \sum_i \phi_i \leq 1\}$. The optimal set is then \[ P^* = \bigl\{\Phi \in P : (\bar{F}^{\!\top}\Phi)_j \geq \ell_j - M^* \;\;\forall j\bigr\}. \]

Algorithm II (Improved)

Algorithm II (Improved) — Belief Network Inversion via Epigraph LP and Hit-and-Run
Input:  $\{\mu_{ij}, \sigma_{ij}\}_{i=1..I,\;j=1..J}$,  observed labels $\ell \in [0,1]^J$,  sample budget $N$,  mixing steps $T$
Phase 1 — Build the mean link matrix
for $i = 1$ to $I$, $j = 1$ to $J$ do
$\bar{f}_{ij} \leftarrow \mu_{ij}$                        (point estimate of each link certitude)
end for
$\bar{F} \leftarrow [\bar{f}_{ij}]$
Phase 2 — Find $M^*$ via the Epigraph Linear Programme
Introduce scalar slack variable $t$.
Solve:
$\min_{t,\,\Phi}\;\; t$
$\text{subject to:}$
$(\bar{F}^{\!\top}\Phi)_j + t \;\geq\; \ell_j$     $j = 1,\ldots,J$
$\phi_i \;\geq\; 0$                              $i = 1,\ldots,I$
$\displaystyle\sum_{i=1}^{I} \phi_i \;\leq\; 1$
Record solution: $M^* \leftarrow t^*$, $\hat{\Phi} \leftarrow \Phi^*$.
Form the optimal set: $P^* \leftarrow \bigl\{\Phi \in P : (\bar{F}^{\!\top}\Phi)_j \geq \ell_j - M^*\;\;\forall j\bigr\}$
Phase 3 — Initialise Hit-and-Run sampler on $P^*$
$\Phi_{\text{current}} \leftarrow \hat{\Phi}$                                                    (start at the LP solution)
$h \leftarrow \{\}$                                                                        (histogram accumulator)
Phase 4 — Monte Carlo posterior over labels
Repeat $N$ times:
// Step A: draw a new $\tilde{\Phi}$ from $P^*$ by hit-and-run
Repeat $T$ steps:
Choose a random direction $d \in \mathbb{R}^I$, $\|d\|=1$
Find the chord $\mathcal{C} = \{\Phi_{\text{current}} + \lambda d : \lambda \in \mathbb{R}\} \cap P^*$
Draw $\lambda \sim \text{Uniform}(\mathcal{C})$;  set $\Phi_{\text{current}} \leftarrow \Phi_{\text{current}} + \lambda d$
End Repeat;  set $\tilde{\Phi} \leftarrow \Phi_{\text{current}}$
 
// Step B: sample the link-certitude matrix for this draw
for $i = 1$ to $I$, $j = 1$ to $J$ do
$\tilde{f}_{ij} \leftarrow \text{clip}\bigl(\mathcal{N}(\mu_{ij},\,\sigma_{ij}^2),\;0,\;1\bigr)$
end for;  set $\tilde{F} \leftarrow [\tilde{f}_{ij}]$
 
// Step C: forward pass and histogram update
Compute $\tilde{L} \leftarrow \tilde{F}^{\!\top}\tilde{\Phi}$                                                      (predicted label vector)
Add $\tilde{L}$ to histogram $h$
End Repeat
Normalise $h$ to unit area.
Output:  $M^*$,  $P^*$,  normalised histogram $h$ over label space

Why this is better than the original

The original Algorithm II searched for the minimum of $M(\Phi)$ by walking the vertices of the polytope $P$. It failed in two ways. First, by the Upper Bound Theorem a polytope in $I$ dimensions with $m$ constraints can have up to $O(m^{\lfloor I/2 \rfloor})$ vertices; the walk becomes hopelessly expensive the moment more than a handful of constraints are added. Second, and more fundamentally, $M(\Phi)$ is not linear: it is a convex, piecewise-linear function whose level sets are nested boxes, not hyperplanes. The Fundamental Theorem of Linear Programming forces the optimum to a vertex only when the objective is linear. Here the optimum balances the residuals across all labels simultaneously, and that balanced point generically lies in the interior of a face of $P$, not at a vertex. (See the 2×2 counterexample: $F = [[0.6,0.2],[0.2,0.6]]$, $\ell = (0.7,0.7)$ — the best vertex returns $M = 0.5$; the true answer is $M^* = 0.3$ at $\Phi^* = (\tfrac{1}{2}, \tfrac{1}{2})$, the midpoint of an edge.)

Replacing triangle distributions with clipped Gaussians for the link certitudes $f_{ij}$ makes the forward pass essentially free. The sum of independent Gaussians is Gaussian: if $f_{ij} \sim \mathcal{N}(\mu_{ij}, \sigma_{ij}^2)$ then, for a fixed weight vector $\Phi$, \[ \bigl(\bar{F}^{\!\top}\Phi\bigr)_j = \sum_{i} f_{ij}\,\phi_i \;\sim\; \mathcal{N}\!\Bigl(\sum_i \mu_{ij}\phi_i,\;\sum_i \sigma_{ij}^2\phi_i^2\Bigr), \] and a single clip to $[0,1]$ is applied at the end. No numerical convolution is needed — no DFT, no flip-and-slide, just one line of arithmetic. For link priors that are not Gaussian, direct convolution (flip-and-slide) remains a valid and accurate fallback, though it is not needed here.

Phase 2 replaces the vertex walk with an epigraph linear programme. By introducing the slack variable $t$, the non-linear sup-norm objective becomes a genuinely linear one: minimise $t$. A linear programme does have its optimum at a vertex — but now at a vertex of the lifted polytope $Q \subset \mathbb{R}^{I+1}$. When that vertex is projected back to $\mathbb{R}^I$ it is generically not a vertex of the original $P$. The LP finds $M^*$ and one exact minimiser $\hat{\Phi}$ in polynomial time, eliminating the combinatorial explosion entirely. The optimal set $P^*$ is then just $P$ intersected with $J$ extra halfspaces — a smaller, well-shaped polytope. Phase 3 samples from $P^*$ uniformly using hit-and-run: at each step, choose a random direction, find the chord through the current point within $P^*$, and draw a new point uniformly along it. This replaces Bob's $\sum \lambda_k v_k'$ step, applied now to the correct polytope. Rather than Dirichlet-mixing over vertices of $P$ (which may not even be in $P^*$), it samples the full ambiguity of the solution uniformly and without boundary bias.

Finally, Phase 4 samples both the belief state $\tilde{\Phi}$ and the link matrix $\tilde{F}$ at every iteration. The original algorithm drew $\lambda_k$ randomly but held the $f_{ij}$ distributions fixed as numerical PDFs, inconsistently treating the link uncertainty. Here each Monte Carlo step draws a fresh $\tilde{F}$ from the clipped-Gaussian priors alongside a fresh $\tilde{\Phi}$ from $P^*$, so the resulting histogram $h$ faithfully propagates both sources of uncertainty into the posterior over labels.

Alternative: Double-Sampling Algorithm (§2.7)

The following is an alternative posteriori algorithm from the original draft paper (Kleinhenz et al., BAMC 2025, §2.7). Instead of using the mean link matrix $\bar{F}$ for the LP solve, it resamples $F$ in an outer loop, producing a different $\hat{\Phi}$ at each outer step. It is presented here for comparison with the main hit-and-run algorithm above.

Algorithm II (Double-Sampling Variant) — Kleinhenz et al. §2.7
Input:  $\{\mu_{ij}, \sigma_{ij}\}$,  observed labels $\ell$,  outer sample budget $B$,  inner sample budget $A$
$L_{\text{post}} \leftarrow []$
Outer loop
Repeat $B$ times:
Sample $\tilde{F}$   —   draw each $\tilde{f}_{ij} \sim \mathrm{clip}(\mathcal{N}(\mu_{ij}, \sigma_{ij}^2), 0, 1)$
Solve epigraph LP with $\tilde{F}$;  find $\hat{\Phi}$ minimising $\|\ell - \tilde{F}^{\!\top}\Phi\|_\infty$
Inner loop
Repeat $A$ times:
Use the same $\tilde{F}$ as the outer step
Sample $\tilde{\Phi}$ from the solution neighbourhood of $\hat{\Phi}$
Compute $\tilde{L} \leftarrow \tilde{F}^{\!\top} \tilde{\Phi}$
Append $\tilde{L}$ to $L_{\text{post}}$
End Repeat
End Repeat
Build and normalise histogram from $L_{\text{post}}$.
Output:  normalised histogram over label space
Conjecture (Kleinhenz et al. §2.7): The double-sampling histogram converges to the same limiting distribution as the single-sampling (hit-and-run) algorithm when $A$ and $B$ are large, by the Central Limit Theorem. This has not been proved.

Methodological Notes

On the a-priori $\Phi$ construction via SSIM. The structural similarity index (SSIM) has been used to rank images in the belief set by similarity to a new query image and to form the prior $\Phi$. NB. SSIM is a poor way of doing this. It is more commonly used to find duplicate or near-duplicate images, not to categorise image content. A better approach: ask a human observer to identify a few belief-set images that resemble the query image and assign weights directly.

On the expert-combination variance formula. An alternative formula sometimes cited in older textbooks for combining $N$ expert estimates adds the variance of the expert means to the sum of within-expert variances: $$\sigma_z^2 = \sigma_1^2 + \cdots + \sigma_N^2 + \mathrm{var}(\mu_1,\ldots,\mu_N).$$ No rigorous mathematical derivation for this formula has been identified. The derivation in the notebooks (BN_A §2.8) uses the standard result for the average of independent Gaussians: $\sigma_z^2 = (\sigma_1^2 + \cdots + \sigma_N^2)/N^2$, which is the correct formula when $Z = (X_1 + \cdots + X_N)/N$.
